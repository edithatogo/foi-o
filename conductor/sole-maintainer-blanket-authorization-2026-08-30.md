## 1. Autonomous Agent Execution Mandate

To minimize approval spam and empower autonomous agentic coding, the repository maintainer grants **blanket, pre-cleared authorization** for the complete lifecycle of repository-owned engineering:

1. **Continuous Code, Contract & Schema Implementation:**
   - Full authority to create, edit, and refactor code, schemas, tests, documentation, and workflow models.
2. **Autonomous Git, PR, and Merge Loop:**
   - Full authority to create local branches, make descriptive commits with git notes, push to origin, open GitHub Pull Requests, monitor CI checks asynchronously via background tasks, and squash-merge once green.
3. **Multi-Agent Subagent Delegation:**
   - Full authority to spawn and coordinate subagents as necessary across tasks.
